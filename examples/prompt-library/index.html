Prompt Library Demo

About

This page demonstrates the Prompt Library drawer component. The drawer provides quick access to all prompts in the Agentic AI UI Control System, organized by category.

How to Use

Keyboard shortcut: Press Cmd+L (Mac) or Ctrl+L (Windows/Linux) to open or close the prompt drawer.

Button: Click the button below to open the drawer manually.

Features

  • Browse prompts grouped by category
  • View full prompt content
  • Copy prompts to clipboard with one click
  • Keyboard accessible (ESC to close, Tab to navigate)
  • Focus trap when drawer is open
Note: This demo requires the repository to be served via a local web server. The prompts are loaded via fetch, which doesn't work with the file:// protocol.
