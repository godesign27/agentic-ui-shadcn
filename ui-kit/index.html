What is a UI Kit?

A UI Kit is a browsable component gallery that allows you to:

  • View all available components in an implementation repository
  • Verify component availability before generating code
  • Preview component examples and copy code snippets
  • Avoid hallucination by referencing actual component implementations

Core Repository vs Implementation Repos

This repository (agentic-ai-ui-control-system) is the core governance and instruction layer. It defines rules, principles, and contracts but does not contain UI components.

UI Kits live in implementation repositories where actual components are built and maintained. Each implementation repository (Bootstrap, shadcn, Material, etc.) has its own UI Kit that showcases its specific component library.
