Rules

The full set is in toaster.agent.json. These are the ones agents get wrong.

Use it for
  • Once, at the application root, whenever ui:toast is used anywhere
Not for
  • More than once — duplicate Toasters render duplicate toasts
  • Inside a route or a conditionally rendered branch

Accessibility

Roles, ARIA wiring and focus management come from the primitive. Do not re-implement them.

KeyboardF8 — focus the viewport
  • Mount it at the root so toasts survive route changes.
