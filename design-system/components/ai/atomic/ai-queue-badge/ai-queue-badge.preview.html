AI Queue Badge

Compact status badge for items in an agent execution queue. Five states with icon + label coding and optional count pill. Ported from canonical AIQueueBadge.tsx.

All states

Queued, Running, Blocked, Needs Approval, and Complete — matching the design system spec.

With count pill

Optional count prop renders a numeric badge inside the shell.

Custom label

Override the default status string with the label prop.

In context — queue card row

Documented states

  • Queued — Neutral gray shell; clock icon. Item waiting, not yet started.
  • Running — Brand-tinted shell; spinner rotates at 0.9s linear (ai-queue-spin).
  • Blocked — Red-tinted shell; prohibition icon. Execution halted.
  • Needs Approval — Signal-tinted shell; info icon. Awaiting human authorization.
  • Complete — Green-tinted shell; check icon. Item finished successfully.

Code example

import { AIQueueBadge } from '@/components/ai/atomic/queue-badge/AIQueueBadge';

<AIQueueBadge status="running" />
<AIQueueBadge status="needs-approval" count={3} />
<AIQueueBadge status="complete" label="Done" />
