AI Handoff Chip

Directional ownership chip for agent-to-agent, agent-to-human, system, and failed handoff transitions. Ported from canonical AIChipHandoff.tsx.

All directions

Five handoff directions with entity glyphs (⬡ agent, ◉ human, ⊞ system) and directional arrow SVG.

Size comparison

md (default) and sm for dense audit rows.

Audit trail context

Time Handoff

Documented directions

  • Agent → Agent — Brand-tinted pill; agent delegating to another agent
  • Agent → Human — Signal-tinted pill; escalation for human review
  • Human → Agent — Success green; human handing work back to AI
  • System → Agent — Purple tint; automated trigger initiating agent task
  • Failed — Red tones with dashed arrow; handoff attempt failed

Code example

import { AIChipHandoff } from '@/components/ai/atomic/chip-handoff/AIChipHandoff';
