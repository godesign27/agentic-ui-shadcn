AI Progress

Progress that communicates AI work — five variants, eleven states, brand gradient fill, and semantic status colors. Ported from canonical AIProgress.tsx.

Determinate running

Primary use case — label, percent, ETA, and brand gradient fill at known percent.

Status states

Semantic fill colors for agentic outcomes — paused, complete, blocked, error, escalated.

Indeterminate

Shimmer animation when percent is unknown. Respects prefers-reduced-motion.

Segmented multi-phase

Workstream stages where phase matters more than exact percent.

Thin & header variants

Embedded bars — 2px thin inside cards, 4px header spanning card top edge.

Live progress demo

Simulates retrieval → analysis → complete lifecycle.

Documented states

  • Running — Brand gradient fill at known percent; smooth width transition
  • Indeterminate — Sliding shimmer when percent unknown
  • Paused — Neutral gray fill; saved progress
  • Complete — Success green with settle animation
  • Blocked — Signal orange fill + Blocked label
  • Error — Error red fill + Failed label
  • Escalated — Deep orange gradient — handed to human review
  • Segmented — Multi-phase bar with per-segment status
