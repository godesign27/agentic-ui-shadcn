AI Message Footer

Decision point at the end of actionable AI responses — primary, secondary, and ghost actions. Ported from canonical AIMessageFooter.tsx.

State variations

1–3 actions — primary grows with flex:1 and minWidth:140px.

In message context

Footer below AI prose — feedback bar may follow separately.

Conditional visibility

visible=false or empty actions renders nothing.

Footer hidden (visible=false)

Documented states

  • Primary only — Single gradient CTA
  • Primary + Secondary — Confirm + Edit (most common)
  • Primary + Secondary + Ghost — Approve + Edit First + Cancel
  • Hidden — No actions or visible=false

Code example

import { AIMessageFooter } from '@/components/ai/atomic/message-footer/AIMessageFooter';

<AIMessageFooter actions={[
  { label: 'Confirm & Apply', variant: 'primary', onClick: handleConfirm },
  { label: 'Edit', variant: 'secondary', onClick: handleEdit },
]} />
