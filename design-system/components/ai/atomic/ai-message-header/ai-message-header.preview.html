AI Message Header

Attribution row for every AI message — BotAvatar, agent label, optional timestamp. Ported from canonical AIMessageHeader.tsx.

State variations

Default md and compact sm — matches design reference.

In message context

Header sits above the response body in chat and card layouts.

No timestamp

Pass undefined to timestamp to hide the recency label.

Documented states

  • Default (md) — 16px BotAvatar, @brand-agent-name (11px / 600), 10px timestamp
  • Compact (sm) — 14px BotAvatar, 10px label, 9px timestamp
  • BotAvatar — #B4BDFF / #5A6DFF / #1F2A66 + white cross-star (no orange ring)

Code example

import { AIMessageHeader } from '@/components/ai/atomic/message-header/AIMessageHeader';

<AIMessageHeader agentLabel="AI Analysis" />
<AIMessageHeader agentLabel="AI Response" timestamp="2 min ago" />
<AIMessageHeader agentLabel="Territory Agent" size="sm" timestamp="2 min ago" />
