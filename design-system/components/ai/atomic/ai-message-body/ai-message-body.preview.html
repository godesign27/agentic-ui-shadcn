Plain AI prose — readable body text via @brand-bubble-body. No bold or headings inside the atom. Ported from canonical AIMessageBody.tsx.

State variations

Three documented content lengths — default size="md" (16px).

Size variants

sm 14px · md 16px · lg 18px — all inherit @brand-bubble-body weight and line-height.

Documented states

  • Standard (md) — Default conversational prose at 16px / 1.55 line-height
  • Short answer — Single-sentence compact response
  • Multi-sentence analysis — Long-form analysis in one prose block
  • Size sm / lg — 14px and 18px typography scale

Code example

import { AIMessageBody } from '@/components/ai/atomic/message-body/AIMessageBody';

<AIMessageBody>
  Based on Q2 territory data, coverage has improved by 8% since the last restructuring.
</AIMessageBody>
