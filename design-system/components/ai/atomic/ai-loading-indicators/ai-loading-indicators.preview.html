AI Loading Indicators

Three loading patterns for AI response stages — working pill, thinking steps, and getting-info fetch. Ported from canonical AILoadingIndicators.tsx.

Response lifecycle

Indicators appear sequentially in a chat thread. Steps advance automatically in this demo.

What drove the Q1 territory misalignment in the Northeast?

All variants

Default (brand tint), tan (companion surface), gray, and white surface variants.

Documented states

  • Working — Compact pill with pulsing label and orbit spinner for quick requests
  • Thinking — Collapsible card with reasoning steps (done / active / pending)
  • Getting info — Three-step card for data fetch + analysis + synthesis
  • Collapsed — Click header to collapse expanded cards to compact pill
  • Tan theme — Warm companion surface with dark tan border (BRAND Tan 70)
  • Gray theme — Neutral gray pill and border for subdued contexts
  • White theme — White pill on light surfaces

Code example

import {
  AIWorkingIndicator,
  AIThinkingIndicator,
  AIGettingInfoIndicator,
} from '@/components/ai/atomic/loading-indicator/AILoadingIndicators';

// Message sent — show working pill immediately
<AIWorkingIndicator />

// Model emits reasoning — swap to thinking indicator
<AIThinkingIndicator />

// Tool call in progress — show getting-info indicator
<AIGettingInfoIndicator theme="tan" />
