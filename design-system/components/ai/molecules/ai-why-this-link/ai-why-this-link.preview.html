AI Why This Link

Minimal inline transparency entry point — ghost link with variant icon. Ported from canonical AIWhyThisLink.tsx.

Inline usage

Appears adjacent to AI-generated content without disrupting hierarchy.

Custom label override

Documented states

  • Why this? — Generic rationale entry (question icon)
  • View rationale — Full reasoning panel (book icon)
  • View sources — Source citation list (external link icon)
  • View assumptions — Underlying assumptions (lightbulb icon)
  • Explain risk — Risk context (warning triangle icon)

Code example

import { AIWhyThisLink } from '@/components/ai/atomic/why-this-link/AIWhyThisLink';

<AIWhyThisLink variant="why-this" onClick={openRationale} />
<AIWhyThisLink variant="view-sources" onClick={openSources} />
<AIWhyThisLink variant="explain-risk" label="Why is this flagged?" onClick={openRisk} />
